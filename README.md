
# Horde Survivor | Roblox Studio

Horde Survivor es un proyecto de videojuego de supervivencia desarrollado en Roblox Studio, utilizando **Luau** como lenguaje de programación.

Este repositorio forma parte de mi portfolio personal como estudiante de la Licenciatura en Desarrollo de Videojuegos en UADE.

## Sobre el proyecto

El proyecto está orientado al desarrollo de una experiencia de supervivencia en Roblox, con lógica de juego programada mediante scripts.

El objetivo de este repositorio es presentar el trabajo de programación realizado y demostrar conocimientos de desarrollo de videojuegos, organización de código y uso de Roblox Studio.

## Tecnologías utilizadas

- **Roblox Studio:** entorno de desarrollo.
- **Luau:** programación de scripts y lógica del juego.
- **GitHub:** almacenamiento y presentación del código fuente.

## Desarrollo técnico

Durante el desarrollo del proyecto trabajé con:

- Programación de scripts en Luau.
- Implementación de lógica y sistemas de juego.
- Organización de componentes dentro de Roblox Studio.
- Integración de scripts con objetos y elementos del juego.
- Pruebas y ajustes de funcionamiento.

## Código fuente

El repositorio contiene scripts exportados desde Roblox Studio.

Los archivos `.lua` y `.luau` permiten consultar el código y analizar su implementación.
